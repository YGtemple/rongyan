## 📖 项目简介

**融研智笔** 是一款 AI 驱动的英语写作智能体 Web 应用，专为中国大学生英语写作考试设计。系统覆盖大学英语四级、六级、专四、专八、考研英语、雅思托福等七类考试评分标准，提供作文批改、智能润色、个性化学习计划、AI 范文生成等全方位服务。

核心理念：**不是简单的语法纠错，而是像私教一样，从批改到范文，带你系统性提升写作能力。**

## ✨ 核心功能

### 📝 智能批改
- 按考试类型精准评分（四级/六级/专四/专八/考研/雅思托福）
- 逐句语法错误标注与修改建议
- 词汇多样性、句式复杂度、逻辑连贯性多维度分析
- 薄弱知识点自动识别与追踪

### ✨ 智能润色
- 一键生成高分润色版本
- 保持原意的同时提升表达质量
- 标注修改理由，学习为什么这样改更好

### 📚 个性化学习计划
- 基于历史批改数据生成专属学习路径
- 针对薄弱知识点定向训练
- 分阶段提升，循序渐进

### 📄 AI 范文生成
- 同主题高分范文参考
- 范文结构拆解，学习写作框架
- 万能句式库，随时调取使用

### 📊 学习数据分析
- 总作文数、评分等级、掌握知识点统计
- 薄弱知识点可视化展示
- 进步趋势追踪，看得见的提升

## 🚀 快速开始

### 本地预览

```bash
# 克隆仓库
git clone https://github.com/YGtemple/rongyan.git
cd rongyan

# 直接用浏览器打开 index.html
# 或使用本地服务器
python3 -m http.server 8080
# 访问 http://localhost:8080
```

### 配置 API

在 `index.html` 中找到 API 配置部分，填写你的后端接口地址：

```javascript
const API_URL = "https://your-api-endpoint.com";
```

> 未配置 API 时为演示模式，界面可正常操作但返回模拟数据。

## 🎨 设计特点

- **三栏专业布局** — PC 端信息密度高，功能分区清晰
- **双端自适应** — 自动检测屏幕尺寸，PC 端/移动端完美适配
- **标签页组织** — 四大功能模块用标签页切换，不拥挤
- **学习数据侧栏** — 左侧实时展示学习进度和薄弱点
- **万能句式侧栏** — 右侧随时调取高分句型
- **本地数据持久化** — 用户数据存储在 localStorage，无需登录

## 💡 使用技巧

1. **先选考试类型** — 不同考试评分标准不同，先选对类型再开始
2. **输入完整作文** — 批改效果依赖完整的作文内容
3. **对照润色版本** — 仔细看修改理由，学习为什么这样改更好
4. **定期查看薄弱点** — 左侧侧栏的薄弱知识点是你下一步的提升重点
5. **积累句式库** — 把好用的句型加入收藏，写作时随时调用
